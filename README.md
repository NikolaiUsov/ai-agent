## Safety AI agent:

### Описание
Интеллектуальный ассистент формирует ответы на основе данных локальной базы знаний, а при необходмости — подтягивает дополнительную информацию из Интернета.  
Агент автономно выбирает инструмент для решения задачи, имеет PII-фильтрацию, блокирует подозрительные запросы (Injection-детекция), также настроена базовая оценка безопасности оветов агента. Все llm-вызовы трассируются в langfuse

### Использованные технологии
- **Python**
- **LLM**: OpenAI через LangChain 
- **RAG / векторный поиск**: FAISS
- **Framework**: LangGraph, LangChain (Core, Classic, Community, huggingface)
- **Embeddings**: HuggingFaceEmbeddings
- **Search API**: DuckDuckGo
- **Инструменты для повышения качества ответов**: CrossEncoderReranker, Query Expansion 
- **Инструменты контроля и защиты**: Langfuse, LLMSecOps

### Структура

*   `llm.py` — Основной файл ИИ-агента.
*   `rag.py` — Скрипт для первичной обработки PDF и создания векторной базы.
*   `requirements.txt` — Информация о версиях библиотек.
*   `docker-compose.yml` — Локальный Langfuse.
*   `filters.py` — Функции-эвалюаторы.
*   *База знаний* — Папка для размещения данных базы знаний (PDF).
*   *Векторная БД* — Локальное хранилище векторных представлений (создается автоматически)

### Быстрый старт

1. Клонировать репозиторий
```bash
git clone <url>
```

2. Поднять локальный Langfuse
```bash
docker compose up -d
```
3. Настроить окружение
```bash
# Рекомендуемая версия Python: 3.10-3.12
python -m venv venv
# Windows:
.\.venv\Scripts\Activate.ps1
# Linux/macOS:
source .venv/bin/activate
pip install -r requirements.txt
```

Примечание: если установка из `requirements.txt` падает из-за несовместимых/опечатанных пакетов, установите зависимости вручную по импортам из файлов  `llm.py`, `rag.py`.

4. Настроить API-ключи
- **OPENROUTER_API_KEY**: https://openrouter.ai/keys
- **LANGFUSE_PUBLIC_KEY**: Локальный Langfuse → Settings → API Keys
- **LANGFUSE_SECRET_KEY**: Локальный Langfuse → Settings → API Keys


5. Создание векторной базы знаний (RAG)

*Перед запуском бота необходимо индексировать базу знаний. База должна находиться в корневой папке проекта. Запустите скрипт и дождитесь его выполнения:*

```bash
python rag.py
```

*После того как база данных успешно создана, запустите агента:*

6. Запуск ИИ-агента на локальном веб-сервере

```bash
python -m uvicorn web.api:app --reload --port 8000
```

- `web.api:app` — путь к FastAPI-приложению (файл `web/api.py`, переменная `app`)
- `--reload` — автоматическая перезагрузка при изменении кода (удобно при разработке)
- `--port 8000` — порт сервера

**далее откройте в браузере**

```
http://localhost:8000
```

Вы увидите страницу чата. Введите вопрос и нажмите «Отправить».

### Примеры вопросов и ответов

**Запрос** - Что такое ReAct паттерн и как он работает в ИИ-агентах?

**Ответ агента**:

**ReAct (Reasoning + Acting) — это паттерн поведения ИИ-агентов**, который объединяет **логическое рассуждение** и **выполнение действий** в рамках итеративного цикла. Вот как он работает:

#### **Основные этапы цикла ReAct:**
1. **Рассуждение (Reasoning):**
   Агент анализирует текущую ситуацию, задаваясь вопросами вроде:
   - Что мне нужно сделать?
   - Какие данные у меня есть?
   - Какие действия доступны?

2. **Действие (Acting):**
   Агент выбирает и выполняет конкретное действие (например, вызывает инструмент, отправляет запрос, обновляет состояние).

3. **Наблюдение (Observation):**
   Агент получает результат выполненного действия (например, ответ от API, изменение состояния системы).

4. **Повторение:**
   Результат действия вносится в новое рассуждение, и цикл повторяется до завершения задачи.

#### **Ключевые особенности:**
- **Гибкость:** Агент адаптируется к новым данным, полученным в процессе выполнения действий.
- **Прозрачность:** Каждый шаг (рассуждение → действие → результат) виден и может быть отлажен.
- **Ограничения:**
  - **Избыточное использование токенов:** Много итераций могут увеличить затраты на вычисления.
  - **Риск ошибок:** Ошибки в одном шаге могут распространяться на последующие (каскадные ошибки).

#### **Пример использования:**
Представьте, что агент должен найти информацию о погоде:
1. **Рассуждение:** "Нужно узнать текущую температуру в Москве."
2. **Действие:** Вызывает API-погоды.
3. **Наблюдение:** Получает ответ: "Температура: 25°C."
4. **Рассуждение:** "Теперь нужно сообщить пользователю."
5. **Действие:** Отправляет сообщение с результатом.
